Reports unused GDShader symbols.

This inspection reports local variables, constants, parameters, uniforms, varyings, structs, and helper functions that are declared but never referenced. Built-in processing functions such as fragment, vertex, and start are not reported as unused. Top-level symbols in include files are not reported unless the option is enabled. 

uniform float unused_uniform; // never used

void fragment() {
    float unused = 1.0; // never used
}

float helper() {
    return 1.0;
} // never called
